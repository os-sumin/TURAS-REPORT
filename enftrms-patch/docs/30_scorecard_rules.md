# 5차원 스코어카드 산식

본 산식은 `src/main/resources/rules/scorecard.yml`에 외부화되어 있으며, 비개발자가 수정 가능. 수정 시 `RULE_VERSION`을 올려 `TFEE_PRED_RULE_VER`에 스냅샷 보관.

## D1. 과제 사업화 적합성 (20점)

| 세부지표 | 만점 | 산출 |
|---|---|---|
| 과제명 ↔ 기업 KSIC 적합도 | 8 | 텍스트 임베딩 코사인 유사도 → 0.8↑=8, 0.5↑=4, 그 외 0 |
| 과제 기술분야의 제품화 가능성 | 7 | 키워드(실증/시제품/인증) 매칭 건수 × 1.5 (상한 7) |
| 과제 종료 후 경과기간 | 5 | 12~24개월=5, 6~12개월=3, 24~36개월=2, 그 외 0 |

## D2. 기업 재무·사업화 체력 (20점)

| 세부지표 | 만점 | 산출 |
|---|---|---|
| 매출 증가율 (전년 대비) | 6 | >20%=6, >10%=4, >0%=2, 그 외 0 |
| 영업이익률 | 4 | >5%=4, >0%=2, 그 외 0 |
| 부채비율 | 3 | <150%=3, <300%=1, 그 외 0 |
| 현금성자산 / 정부지원금 | 3 | >1=3, >0.5=2, 그 외 0 |
| R&D 비중 (R&D비/매출) | 2 | >5%=2, >2%=1, 그 외 0 |
| 유형/무형 자산 증가율 | 2 | >10%=2, >0%=1, 그 외 0 |

## D3. R&D 자본효율·기술료 이력 (20점) ★ 엑셀 양식 직접 매핑

| 세부지표 | 만점 | 산출 | 데이터 출처 |
|---|---|---|---|
| 과거 기술료 발생 여부 | 6 | 발생=6, 미발생=0 | `TFEE_PRED_ANSWER.ANSWER_Y` 동일 기관 이력 |
| 누적 기술료 회수율 | 5 | Σ TFEE_AM / Σ TTL_PAY_GVSTM_AM, percentile rank | 동일 |
| 과제별 회수율 | 4 | TFEE_AM / TTL_USE_GVSTM_AM | `PS_ORGN_TFEE_CCLT` |
| 기술료 발생 속도 | 3 | 종료일~최초발생일 ≤12개월=3, ≤24개월=2, ≤36개월=1 | `PS_TECH_IPMT_CNTR.TECH_IPMT_CNTR_DE` |
| 반복 발생 여부 | 2 | 2년 연속=2, 1회=1 | 연도별 집계 |

※ 회수율 등급화는 평균이 아닌 **percentile rank** 적용 (사업기획서 V-3 주석).

## D4. 시장·산업 신호 (20점)

| 세부지표 | 만점 | 출처 |
|---|---|---|
| 산업 매출 성장률 | 3 | KOSIS / ISTANS |
| 사업체·종사자 수 증가율 | 2 | KOSIS |
| 유사 R&D 과제 증가율 | 2 | NTIS |
| 유사 과제 사업화 성과 | 2 | NTIS |
| 관련 공공입찰 건수 | 4 | 나라장터 |
| 관련 계약금액 | 2 | 나라장터 |
| 수출입 증가율 | 2 | K-stat / 관세청 |
| 특허출원 증가율 | 2 | KIPRIS |
| 정책·규제 이벤트 | 1 | 정책자료 / 뉴스 |

## D5. 기업 실행 신호 (20점) — 기존 언론분석 모듈 재사용

이벤트별 점수 합산. 기존 `company_news_analysis` 결과의 기사를 GPT로 `eventType`까지 분류하도록 프롬프트 확장 필요.

| 이벤트 | 점수 |
|---|---|
| A 과제 관련 제품 출시 | +5 |
| 공급계약·수주 | +5 |
| 양산 개시 | +5 |
| 인증·인허가 획득 | +3 |
| 투자유치 | +3 |
| 공장 증설·설비투자 | +2 |
| 특허·상표 출원 | +1 |
| 소송·분쟁 | −3 |
| 회생·폐업·휴업 | −10 |
| 사업 철수 | −10 |

합산 후 max(0, min(20, score)).

## 등급 기준

| 총점 | 등급 코드 | 라벨 | 실무 조치 |
|---|---|---|---|
| ≥ 80 | VERY_HIGH | 매우 높음 | 우선 확인 및 증빙 요청 |
| ≥ 65 | HIGH | 높음 | 기술실시 여부 확인 |
| ≥ 50 | MID | 보통 | 모니터링 |
| ≥ 35 | LOW | 낮음 | 미실시 사유 확인 |
| < 35 | VERY_LOW | 매우 낮음 | 후순위 관리 |
